Sobre o aplicativo

O M&E Backup é um agente da M&E Sistemas para backups agendados de bancos de dados PostgreSQL. Quando configurado pelo cliente, ele utiliza o Google Drive para armazenar backups na conta do próprio cliente.

Dados do Google e finalidade

Para utilizar o Google Drive, o usuário autoriza o acesso solicitado pelo aplicativo na tela de consentimento do Google. O M&E Backup usa esse acesso para enviar os arquivos de backup ao Google Drive do cliente, conforme a configuração realizada.

Os backups podem conter os dados existentes nos bancos PostgreSQL do cliente. O cliente é responsável pelo conteúdo dos bancos e pela configuração dos backups.

Armazenamento e controle

Os arquivos enviados ficam no Google Drive da conta autorizada pelo cliente. O usuário pode gerenciar os arquivos no próprio Google Drive e revogar a autorização do aplicativo nas configurações de segurança da Conta Google.
